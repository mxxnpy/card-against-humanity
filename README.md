# Card Against Humanity

Este é um projeto Angular para criar um jogo Cards Against Humanity.

## Requisitos

- Node.js (versão 18 ou superior)
- npm (versão 9 ou superior)

## Instalação

```bash
npm install
```

## Executar o projeto

```bash
npm start
```

O aplicativo estará disponível em `http://localhost:4200/`

## Build

```bash
npm run build
```

## Testes

```bash
npm test
```
